# 📘 Gerenciamento para clínicas

Uma API inteligente e eficiente para gestão de clínicas, com cadastro de serviços e agendamento de consultas por horário.

---

## 🚀 Tecnologias Principais

- FastAPI — Framework moderno e de alta performance para APIs.
- FastAPI CLI & Cloud CLI — Gerenciamento e deploy de apps.
- Fastar — Bindings de alto nível para manipulação de arquivos `.tar`.
- AnyIO — Framework de concorrência e rede.
- Click & Colorama — Criação de CLIs com suporte a cores.
- Email Validator — Validação robusta de endereços de e-mail.
- DNSPython — Toolkit para manipulação de DNS.
- Certifi — Bundle de certificados da Mozilla.
